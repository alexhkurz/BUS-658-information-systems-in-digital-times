# BUS 658: Information Systems in Digital Times

This is the repository for the course BUS-658 Information Systems in Digital Times in Spring 2026 taught by Seth Benzell and Alexander Kurz. (Thu 7-10pm, Beckman 104).

Each week centres on a topic with assigned readings. Before class, students submit their conversation with an LLM about those readings, along with an interesting question for discussion. The course emphasises using AI both to extract insight from texts and to develop substantive, high-quality questions.  

Lectures provide the theoretical background for each topic. Labs build practical activities around the topic, often with a data science focus. Short student presentations on the lab work conclude the class.
